# PostPock 前端

React 19 + Vite 8（纯 JavaScript）。

```bash
npm install
npm run dev      # http://localhost:5190
npm run build    # 产物在 dist/，放到 .exe 同级的 frontend/ 目录即可被后端代理
```

## 分层（UI 与数据分离）

| 目录 | 职责 |
| --- | --- |
| `src/ui/` | 只做界面与交互：页面（home / author / post / login）、浮层（search / export / sync / settings / editors / backup / mcp / welcome）、组件、图标、星月夜画作 |
| `src/bridge/` | 中间层：React hooks（Suspense 页面数据、带主题失效的缓存、实时任务/连接/设置 store、乐观的页面设置） |
| `src/data/api/` | 数据层对外 API，UI 只经由 bridge 调用这里 |
| `src/data/domain/` | 业务规则：导出文件名模板校验与展开、目录树规划、搜索（各搜索域取并集） |
| `src/data/mock/` | 本轮的模拟后端（硬编码、可确定生成的数据、任务模拟器）：`backend.js`（文章库、连接、任务、同步、导出、文件夹、设置）、`access.js`（密码登录、服务器模式、MCP 密钥、首次启动）、`snapshots.js`（数据备份快照）。接入 Go 服务时把 `data/api` 引用的这三个模块换成 HTTP/SSE 客户端即可，每个接口的数据结构写在 `data/api/index.js` 的注释里 |

## 其他约定

- 路由为 hash（`#/`、`#/author/:id`、`#/post/:id`），任何目录下都可直接托管。
- 字体只使用 `public/fonts/` 中的三款 TTF；图标全部来自 `src/ui/icons/Icon.jsx`，禁止 emoji。
- 首页星月夜：`src/ui/art/starry/`（厚涂引擎移植自 The Pelican Test 第 12 幕，MIT）。在 Web Worker 中绘制并缓存到 IndexedDB，之后访问直接解码。
- 文案在 `src/i18n/`（简体中文 / English）。
- 模拟数据层用浏览器存储保存设置、各作者的页面设置与上次导出配置（对应后端的 config.toml / sqlite）；新增的作者与文章只保存在内存中，刷新后回到样例库。
- 设置里把数据库路径改为其他目录会切换到一个空库，可用来查看空状态；改回默认路径即恢复样例库。
- 同步清单目前一次渲染全部条目（按作者分组并使用 `content-visibility`），数百到一两千条没有问题；若单次检查达到上万条，建议给列表加虚拟滚动。

## 访问、备份与 MCP

| 功能 | 入口 | 模拟层的行为 |
| --- | --- | --- |
| 首次启动引导 | 配置里尚未完成引导时自动打开 | 地址加上 `?first-run`（如 `http://localhost:5190/?first-run#/`）可再看一次；只有引导结束时才保存选择，密钥除外（点击“创建密钥”时就创建，便于立刻复制） |
| 登录页 | 开启密码登录后打开页面 | “忘记密码”说明在 PostPock 终端输入 `/reset_pwd`，或在 `config.toml` 中关闭密码保护（由后端实现）；会话存在 `sessionStorage`，新标签页需要重新登录；“设置 → 访问与安全 → 立即锁定”可直接回到登录页；连续输错 5 次需等待 30 秒 |
| 密码登录 | 设置 → 访问与安全 | 开启时要设置密码，保存后立即生效；修改或关闭需要当前密码。模拟层为了校验会保存明文，后端只应保存哈希 |
| 服务器模式 | 设置 → 访问与安全；开启后顶栏出现服务器按钮（地址与二维码） | 后端启动时读取该设置，所以开关后要重启才生效；模拟层把“刷新页面”当作重启 |
| 数据备份（快照） | 设置 → 数据与备份 → 数据备份 | 创建快照时必须选择包含哪些作者（默认选中有更改的作者）：只保存这些作者的更改，其他作者的更改仍然待保存；平台与页面设置属于整个库，总会一起保存。每个快照记录当时的文章、作者与自定义平台：载入较早的快照会让样例库真的回到当时（未保存到快照的内容会丢失）；删除只是从时间线隐藏，可撤销；`D:\PostPock\backup` 里预置了一个可导入的快照文件，导出的文件也会出现在所选文件夹中 |
| MCP | 设置 → MCP → 管理密钥 | 密钥保存在模拟配置里（样例含 3 个）；完整密钥只在创建与重新生成时返回一次 |

快照在后端以版本历史的方式保存整个数据库目录，“快照共占用”显示的是这份历史的总大小；界面上不为单个快照显示大小，也不提及具体实现。
